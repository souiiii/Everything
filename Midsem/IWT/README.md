## Planner Interpretation

Treat IWT as a **narrow midsem track covering only Module I through CSS**.

The preparation block should focus on:

1. quick revision of Web/HTTP/URL fundamentals;
2. HTML structure, tags, and forms;
3. CSS syntax, selectors, layout, positioning, specificity, and common styling features.

Do not allocate time for later modules.
